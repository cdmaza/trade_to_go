# Changelog: 2026-10-21 21:32 (MYT)

Restructured the project into the `trade_to_go` package tree (Phase 0).

## Added
- `pyproject.toml` (uv, Python 3.12, `ttg` CLI entry point) and `.python-version`.
  Extras: `backtest` (vectorbt), `broker` (moomoo-api). Dev group: pytest.
- `.env.example` for secrets (Telegram, FRED, EDGAR User-Agent, Tiingo, OpenD).
- `config/settings.yaml`, `config/universe.yaml`, `config/alerts.yaml`.
- `src/trade_to_go/core/`:
  - `config.py`: settings from YAML + `.env`; `TTG_ROOT` override; `require_env()`.
  - `log.py`: logging setup.
  - `calendars.py`: XKLS (Bursa), XNYS, XLON (proxy for LBMA days).
  - `storage.py`: immutable raw landing with `_manifest.jsonl` (sha256, url, fetched_at);
    validated Parquet writes for staging/curated; DuckDB views named `<layer>_<dataset>`;
    `ops.sqlite` schema (`run_log`, `signal_state`, `alert_log`, `sent_dedupe`,
    `paper_orders`); `track_run()` context manager.
  - `http.py`: requests session with retries, honest User-Agent, rate limit.
  - `telegram.py`: ported from legacy.
- `sources/base.py` (`Source` protocol, `RawPayload`) and `sources/bgd.py` (ported scraper).
- `schemas/bgd.py`: pandera schema for `staging/bgd_quotes`.
- `pipelines/gold.py`: `ingest_bgd()`, `build_bgd_staging()`.
- `signals/base.py`: `Signal` dataclass (state, price, invalidation, hit rate, backtest id).
- Package stubs with scope docstrings: `features`, `alerts`, `backtest`, `reconcile`, `broker`.
- `cli.py`: `ttg init | ingest <source> | stage <source> | status`.
- `deploy/systemd/ttg-ingest-bgd.{service,timer}` (hourly).
- Tests: `tests/unit/test_storage.py`, `tests/golden/test_bgd_parse.py` with a real captured
  BGD message. 7 tests pass.
- `research/README.md`, `legacy/README.md`.

## Changed
- BGD scraper:
  - No longer connects at import time; reads one message with a 15 s timeout.
  - Sends an honest User-Agent instead of a browser string (verified working live).
  - Now keeps `bursaTime` (as `quoted_at`, UTC) and `bursaCode`.
  - Missing prices fail validation instead of being stored as 0.
  - `spread` = sell − buy. The legacy code stored buy − sell in a column named `Volume`.
- Storage moved from SQLite `bursaGold` to `data/raw` + `data/staging/bgd_quotes/*.parquet`.
- `README.md` rewritten for uv and the new layout. `.gitignore` covers `.venv`, `data/`, `reports/`.
- `doc/todos.txt` replaced with the full phased roadmap (original Plan 1 kept at the top).

## Moved
- `src/main.py`, `src/extract/`, `src/data/`, `src/notify/`, `sql/` → `legacy/` (unchanged).
- Root `CHANGELOG.md` → `codelog/CHANGELOG_legacy.md`.

## Not ported
- `goldMinMax.json` running min/max (kept in `legacy/data/temp/`). It will become a feature
  computed from staging data.
- `notifier.py` (it referenced a missing `src.common` module and stock fields). Replaced by
  the planned `alerts/` package.
