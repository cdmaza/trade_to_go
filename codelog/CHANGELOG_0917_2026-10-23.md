# Changelog: 2026-10-23 09:17 (MYT)

Goal: a command that says what to do now for gold and for stocks (own watchlist plus a few
potential names), instead of only alerting on pre-registered rule changes.

## Added
- `calls/` package:
  - `indicators.py`: trend states reusing the backtested rule functions, in two readings
    (official = last completed month-end, live = today's price as this month's close), plus the
    exact price levels that flip each rule; returns, 12-1 momentum, RSI, drawdown, volatility.
  - `gold.py`: BUY (>= 3 of 4 checks up) / HOLD (2) / SELL (<= 1). Uses curated GOLD_MYR if LBMA is
    imported, else BNM Kijang Emas mid. Reports the Kijang buy/sell spread (about 4%), data age,
    short-history warning and the latest backtest verdict.
  - `stocks.py`: BUY needs uptrend on both readings, positive 12-1 momentum and RSI below 75;
    SELL needs downtrend on both; otherwise HOLD. Candidates ranked by momentum rank (50%),
    3-month return rank (30%), low volatility (10%), +10% if also a factor-screen pick.
  - `watchlist.py`, `service.py` (report, refresh, change detection, JSON history), `render.py`
    (terminal, Markdown, Telegram HTML, standalone dark/light HTML dashboard).
- `calls/replay.py` + `research/kijang_rules_check.py`: replays SMA10 / 12m momentum on the same gold
  prices with half the real buy/sell spread each way; `ttg call` prints it under the gold reading.
  Kijang Emas 2021-07 to 2026-09 (59 months, 2.0% each way, in-sample, bull market):
  holding 17.8%/yr (max DD -22%); SMA10 11.5% (8 trades, DD -31%); 12m momentum 17.2% (3 trades);
  both rules 12.0%. Neither timing rule beat holding. Supports the DCA default; says a SELL
  should be read cautiously, not that the rules are useless (too short a sample to say).
- CLI: `ttg call [--refresh] [--notify] [--markdown] [--no-html]`, `ttg watch add|remove|list`.
- Config: `config/watchlist.yaml` (yours), `candidates` in `config/universe.yaml` (starter pool of 30
  large US names, to be replaced), `calls` thresholds in `config/settings.yaml`.
- Storage: `call_state` table in ops.sqlite (last label per symbol). First run is a silent baseline;
  afterwards a changed label, or a stock newly rated BUY in the potential list, is reported.
- `pipelines/equities.universe_symbols()` now also fetches the watchlist and candidates.
- `deploy/systemd/ttg-daily.service` runs `ttg call --refresh --notify` last.
- Tests: `tests/unit/test_calls.py` (14 tests). Suite: 58 passed, 6 skipped.
