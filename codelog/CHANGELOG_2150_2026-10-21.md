# Changelog: 2026-10-21 21:50 (MYT)

Phase 1 (gold data, MYR) and Phase 2 (gold research and backtest).

## Findings that shaped the design
- BNM OpenAPI: USD/MYR from 2008 (noon `session=1200` is the only session with a middle
  rate); Kijang Emas only from 2020-07 (earlier months return empty).
- LBMA: the old public JSON (`prices.lbma.org.uk/json/gold_pm.json`) now returns 403. History
  is only on the LBMA portal (non-commercial self-certification), so it is imported from a file.
- Bundesbank's London gold series (BBEX3) returns 404, so it can't replace LBMA.
- World Bank Pink Sheet gold is a MONTHLY AVERAGE (LBMA PM to May 2025, spot average after).
  Averages smooth returns and inflate Sharpe, so it is used only as a cross-check.

## Added
- Sources: `sources/bnm.py` (FX + Kijang, monthly raw files, latest fetch wins),
  `sources/lbma.py` (manual import, CSV/XLSX, auto-detects Date and USD/PM columns),
  `sources/worldbank.py` (finds the current workbook link on the official page),
  `sources/fred.py` (API only; DFII10, DTWEXBGS; key kept out of stored URLs).
- `schemas/gold.py`: pandera schemas for usdmyr_daily, kijang_daily, gold_usd_daily,
  gold_usd_monthly_avg, macro_daily, gold_myr_daily.
- `pipelines/gold.py`: BNM backfill (missing months, plus the current and previous month
  always refetched), LBMA import, World Bank, FRED, and `derive_gold_myr()` with two timing
  conventions:
  - `kl_noon` (default): previous London PM fix × BNM noon rate. Known at 12:00 KL.
  - `same_day`: same-day fix × noon rate.
  Each row carries an `available_at` timestamp.
- `reconcile/gold_myr.py`: tracking error (annualised std of log-return differences, daily and
  monthly), correlation and premium against Kijang Emas, BGD and the World Bank; writes
  `reports/reconciliation_<date>.{md,json}`. Pass thresholds were set in settings.yaml before
  the first run.
- `pipelines/export.py`: `ttg export` writes an Excel workbook (tz-aware columns made Excel-safe).
- Features: `features/trend.py`, `momentum.py` (incl. MOP ex-ante vol), `macro.py` (lagged
  as-of for weekly-published DTWEXBGS).
- `signals/gold_rules.py`: Faber SMA, MOP TSMOM (long/flat, since BGD can't be shorted), real-yield/dollar
  regime, SMA+regime, invalidation levels.
- Backtest: `engine.py` (contributions, one-way costs, execution on the next price after the
  month-end, net liquidation, IRR), `metrics.py`, `deflated_sharpe.py` (Bailey & López de Prado),
  `trials.py` (DuckDB `backtest_trials` registry), `walk_forward.py`, `costs.py` (BGD half-spread),
  `gold_study.py` (report + pre-registered decision rule), `replication.py`.
- Config: `gold`, `reconcile`, `backtest` sections in settings.yaml; `config/replication.yaml`.
- CLI: `ttg ingest bnm|worldbank|fred`, `ttg import lbma <file>`, `ttg build gold`,
  `ttg reconcile`, `ttg backtest gold [--provisional]`, `ttg export`.
- Tests: derive/reconcile stats, LBMA/FRED parsers, BNM golden files, backtest engine, metrics,
  DSR, walk-forward, rules, replication harness (skips until targets are filled).
  32 passed, 6 skipped.

- Provisional reconciliation: Kijang vs World Bank × FX (monthly averages, 71 months):
  premium 3.99%, monthly correlation 0.989, TE 1.89%.
- Provisional backtest (World Bank monthly averages, biased, no decision), 2009-01 to 2026-09,
  1.805% one-way cost:
  - DCA: IRR 11.24%.
  - SMA10: IRR 7.55%.
  - TSMOM12: IRR 9.72%.
  - Walk-forward: 12.03% vs DCA 13.93%.
  No rule beat DCA.

## Added (Phase 4: alerts)
- `alerts/service.py`: state machine on `signal_state`.
  - Fires on state changes only; the first observation initialises state silently.
  - Dedupe key is signal|instrument|state|as_of. A send failure leaves the alert unmarked, so it is retried.
- `alerts/formatter.py`: Telegram HTML with signal, state change, price, invalidation level
  (or "macro regime flip") and backtest hit rates at 5, 20 and 60 days.
- `alerts/scorer.py`: forward scores at 5, 20 and 60 trading days (long = asset return, flat = 0,
  short = negative), benchmark return over the same days, `summary()` for success criterion 3.
- `signals/live.py`: evaluates enabled rules on the last COMPLETED month with the same rule code;
  hit rates come from the latest non-provisional gold backtest report.
- `pipelines/prices.py`: daily price lookup by instrument (GOLD_MYR, KIJANG, BGD, equities).
- `config/alerts.yaml`: gold_sma10 and gold_tsmom12 defined but `enabled: false` until the
  backtest earns them; benchmark instruments for scoring.
- CLI: `ttg alerts run [--dry-run] | score | report`.
- Tests: `tests/unit/test_alerts.py`, `tests/parity/test_parity.py` (live == backtest at T).

- `broker/moomoo_paper.py`: simulator orders only (TrdEnv.SIMULATE), logged to `paper_orders`.
- `doc/survivorship.md`: what each source does and doesn't cover, and how to report it.
- CLI: `ttg ingest tiingo|moomoo|edgar`, `ttg screen us`. universe.yaml: `symbols`, `top_fraction`.
